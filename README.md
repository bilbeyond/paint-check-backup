# 涂布表面均匀性识别系统

拖拽上传涂层照片，自动分析表面均匀性，给出百分比评分与五星评价。纯前端静态页面，图片只在浏览器本地分析，不上传任何服务器。

## 功能

- 拖拽 / 点击 / 粘贴上传，支持 JPG / PNG / WebP，可批量
- 上传后自动分析，输出 0–100% 综合得分 + 五星评价（支持半星）
- 四项指标：色泽一致性、表面纹路均匀性、气泡、裂纹
- 单条记录删除、一键清空

## 部署

纯静态站点，直接把本目录发布到任意静态托管即可（GitHub Pages / Vercel / Nginx 均可），无需构建步骤。

GitHub Pages：仓库 Settings → Pages → Source 选 `main` 分支根目录。

## 演示模式说明

`js/app.js` 顶部有 `DEMO_MODE` 开关，当前为 `true`：无论上传什么图片，第 1 张固定 98 分、第 2 张 99 分，依次循环（点「清空结果」重新从 98 开始），用于演示时保证结果稳定。

把 `DEMO_MODE` 改为 `false` 即恢复真实图像分析算法（`js/analyze.js`，双因子评分：色泽一致性 0.8 + 表面纹路均匀度 0.2，附带气泡/裂纹形状检测）。
